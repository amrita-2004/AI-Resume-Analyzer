REST API Documentation

POST
/api/analyze
Multipart resume upload + optional JD text. Emits SocketIO live progress and returns clean JSON analysis.
POST
/api/job-match
Calculates TF-IDF similarity, keyword overlap, missing skills, and priority gap roadmap.
GET
/api/dashboard
Retrieves live dashboard cards (ATS score, Job match %, Skill match %, Readiness index, Resume status).
GET
/api/history
Retrieves historical resume analysis records from MongoDB or local store.
POST
/api/reanalyze
Compares improved resume against baseline analysis to calculate delta scores and resolved gaps.

WebSocket Real-Time Workflow

  • 10% Resume Uploaded & Magic Byte Validated
  • 30% Text Extracted (PyPDF2 / python-docx)
  • 50% NLP Processing & Skill DB Keyword Search
  • 70% ATS Scoring & TF-IDF Vectorization
  • 90% AI Rejection Vectors & Recovery Roadmap
  • 100% Dashboard Auto-Updated (No Page Refresh)

2FA Security Workflow

  • Password Hashing: Werkzeug PBKDF2 Hashing
  • Email OTP: 6-Digit Code with 5-Minute Expiry
  • PyOTP Authenticator: TOTP QR Code scanning
  • Lockout Protection: Throttling after 5 failed attempts
  • Secure Cookies: HTTPOnly, SameSite Session Cookies
